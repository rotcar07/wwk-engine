# wwk-engine

一个基于 NoneBot2 开发的狼人杀机器人。

## Features

- 支持十余种身份
- 自动夜晚流程
- 自动讨论流程
- 自动投票
- ForwardMsg 复盘
- 观察者模式

## Requirements

Python 3.11+

NoneBot2

OneBot v11

## Installation

Help yourself.

## Commands

以下指令大部分存在中文别名，请自行到代码中寻找。

帮助指令：

* `whelp`：查看玩家通用指令
* `wolfhelp`：查看狼人阵营指令
* `otherhelp`：查看特殊身份指令
* `whelpsu`：查看管理员指令（仅 SuperUser）

### 通用玩家

| 指令             | 说明       |
| -------------- | -------- |
| `wjoin`        | 加入游戏     |
| `wshow`        | 查看当前游戏状态 |
| `wvote <玩家编号>` | 白天投票     |
| `wpass`        | 结束当前发言   |

---

### 狼人阵营

> 系统会随机指定一名**主狼**，只有主狼可以使用 `wkill`。若主狼死亡，将自动转移给其他存活狼人。

| 指令             | 说明                         |
| -------------- | -------------------------- |
| `wkill <玩家编号>` | 夜晚击杀目标（仅主狼）                |
| `wconf`        | 确认本夜行动（即使空刀也需要确认）          |
| `wsay <内容>`    | 狼队私聊交流                     |
| `wcut [玩家编号]`  | 自爆；若填写目标编号，则发动白狼王技能（仅私聊可用） |
| `wgun <玩家编号>`  | 黑狼王开枪；填写 `0` 表示空枪          |

---

### 特殊身份

| 身份       | 指令              | 说明          |
| -------- | --------------- | ----------- |
| 预言家      | `wpred <玩家编号>`  | 查验身份        |
| 女巫       | `wsave`         | 使用解药救人      |
| 女巫       | `wpois <玩家编号>`  | 使用毒药        |
| 守卫       | `wguard <玩家编号>` | 守护一名玩家      |
| 猎人 / 黑狼王 | `wgun <玩家编号>`   | 开枪；`0` 表示空枪 |
| 骑士       | `wcut <玩家编号>`   | 发起决斗        |
| 摄梦人      | `wcatch <玩家编号>` | 摄梦目标        |
| 所有夜间身份   | `wconf`         | 确认行动或选择跳过   |

---

### 管理员（SuperUser）

| 指令                        | 说明      |
| ------------------------- | ------- |
| `wstart`                  | 开始游戏    |
| `wstop`                   | 强制结束游戏  |
| `wkick @玩家`               | 将玩家移出本局 |
| `wset <身份列表> <是否诸神> <阵营>` | 设置本局配置  |
| `wday`                    | 强制进入白天  |

身份缩写：

* `Vi`：Villager（村民）
* `Wo`：Wolf（狼人）
* `Wi`：Witch（女巫）
* `Pr`：Predictor（预言家）
* `Gu`：Guard（守卫）
* `Hu`：Hunter（猎人）
* `Id`：Idiot（白痴）
* `WW`：White Wolf（白狼王）
* `BW`：Black Wolf（黑狼王）
* `ES`：Evil Spirit（恶灵骑士）
